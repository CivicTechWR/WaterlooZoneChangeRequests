# Waterloo Zone Change Requests

JavaScript tool for tracking and visualizing zoning change requests in Waterloo.

## About

This project helps residents track and understand zoning change requests in the City of Waterloo, making civic planning more transparent and accessible.

## Tech Stack

- JavaScript

## Status
